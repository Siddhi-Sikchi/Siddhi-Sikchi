## GitHub setup

1. Create the profile repository named exactly `Siddhi-Sikchi` under the GitHub account `Siddhi-Sikchi`.
2. Copy the repository contents into it and push to `main`.
3. Run **Actions → contribution trail → Run workflow** once. The workflow will create/update the `output` branch with the snake animation.
4. Replace/add project URLs in the README if you want the project cards to point to live repositories.

## Notes

GitHub READMEs do not execute JavaScript, so the custom motion is implemented using SMIL inside the SVG assets. The README keeps text intentionally compact and uses visuals for the main recruiter-facing story.
