# Setup

1. Create/open your GitHub profile repository (the repository name should normally match your GitHub username).
2. Copy `README.md` and the `assets` folder into that repository.
3. Replace:
   - `YOUR_GITHUB_USERNAME`
   - `YOUR_LINKEDIN_USERNAME`
4. Keep `assets/profile.png` in the same folder structure.
5. Commit and push.

## Theme
The design uses a dusty-rose / blush palette sampled from the uploaded profile photo, with a deep charcoal background for contrast:
- Background: `#0d1117`
- Rose: `#d47f78`
- Blush: `#e8aaa1`
- Light blush: `#f1c4bc`
- Text: `#e7d8d5`

## Important
GitHub sanitizes some HTML/CSS, so the animation is implemented mainly through SVG assets rather than custom CSS/JavaScript. The GitHub stats/graphs are external image endpoints and require the username to be replaced.
